# Haul Bros website

Static site for Haul Bros junk removal (Katy, Fulshear & Houston area). Served by GitHub Pages at https://haulbros.github.io

- `index.html` — the whole page (HTML, CSS and a little JS for the menu and pickup form)
- `assets/` — logo, job photos and self-hosted fonts (Barlow, Barlow Condensed)

To change prices, text or phone numbers, edit `index.html`.
